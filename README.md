# 弦上二胡 · 手机练功房

一款为手机触控重新制作的二胡模拟器小游戏。

## 在线试玩

https://kayleelin1019.github.io/erhuplay/

## 玩法

- 点选八个音位之一。
- 根据当前乐谱，在弓区向左推或向右拉。
- “跟谱练习”会判定音位和弓向，“自由演奏”不计分。
- 首次触摸页面后，浏览器才会允许播放合成二胡声音。

静态网页源码位于 `site/`，发布版本位于 `gh-pages` 分支。当前页面版本为 `v12`：页面会使用 Safari 的实际可见高度控制在一屏内，地址栏变化时自动调整；推拉弓会连续驱动右侧二胡图层移动；首次打开提供三步新手引导，右上角问号可以再次查看。根目录的 ZIP 文件是旧版项目备份，予以保留。
